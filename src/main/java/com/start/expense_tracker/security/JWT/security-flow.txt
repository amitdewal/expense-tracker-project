     ↓

     ↓
Step 2: Does it start with "Bearer "?
     ↓ YES                    ↓ NO

     ↓
Step 3: Extract username from token
     ↓
Step 4: Load user from DB
     ↓
Step 5: Validate token (username match + not expired)
     ↓ VALID                  ↓ INVALID
Set authentication       Skip → request is unauthenticated
in SecurityContext
     ↓
Step 6: Continue to Controller
